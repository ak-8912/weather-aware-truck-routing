# Weather-Aware Truck Routing

Full stack trip planning foundation for assessing weather exposure along road routes. Backend analysis will use OpenRouteService for routing/geocoding and Open-Meteo for forecasts.

## Development

See [docs/SETUP.md](docs/SETUP.md). The frontend runs at `http://localhost:5173`; the Django API runs at `http://localhost:8000`.
