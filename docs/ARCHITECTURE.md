# Architecture

The repository is a Vite/React TypeScript frontend and a Django REST Framework backend. Browser requests use the API base URL in `frontend/.env`; provider credentials remain in backend environment variables. SQLite is configured for local development. Backend API URLs are grouped under `api/` and version-independent errors use a shared DRF exception handler. Health reporting is served from the trips app and validated through a serializer. JSON logs carry timestamps, severity, logger names, and event metadata. Routing, geocoding, weather, checkpoint generation, and risk analysis will be added in their respective backend apps in later phases.
